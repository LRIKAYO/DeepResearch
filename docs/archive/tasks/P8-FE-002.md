## Key Decisions

- Only checkpoint/stream `citations` feeds Sources. No Tool/Report parsing,
  custom event, claim matching, per-message association, or source persistence.
- Preserve supplied order and duplicates, including duplicate IDs. Render by
  list position rather than treating run-local `c1...` as durable identity.
- Undefined hides the panel; a present empty array explicitly reports a
  successful research with no sources. Loading/error copy keeps the prior
  successful inventory labelled latest completed, without caching or synthesizing
  a replacement list.
- Web provenance uses HTTP(S) links with `target="_blank"` and
  `rel="noopener noreferrer"`; uploaded provenance is filename/section/page
  metadata only. Text is React-escaped, not interpreted as HTML or Markdown.
- The pinned SDK clears history/stream after thread selection in effects.
  Checking recovered history's checkpoint thread ID before displaying Sources
  rejects the prior thread even on the first selection-change render. The
  Stream provider is not remounted, preserving independent Knowledge state.
- The existing getter-preserving scoped submit wrapper and accepted stream
  modes remain unchanged. Reading values/history does not introduce `tools`
  or new custom stream modes.
