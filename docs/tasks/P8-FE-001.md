## Key Decisions

- Project-keyed component state clears immediately on selection change.
  AbortController plus post-await guards discard stale responses even if the
  request resolves after cancellation. No Document state enters the shared
  Project/Session provider.
- Backend remains the authority for validation, ownership, indexing, and list
  order. A POST result is never optimistically appended to the list.
- Upload and list failures are separate: successful indexing plus failed list
  refresh offers a list retry. An interrupted connection does not imply the
  server rolled back; check the list before re-uploading.
- Only three exact documented 422 detail strings can cross the error boundary;
  all other copy is locally selected by status. Raw provider text is discarded.
- No Session dependency, composer changes, multi-format ingestion, preview,
  delete, polling, background jobs, or upload library.
