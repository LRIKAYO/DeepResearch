# P7-003B — Run-local Citation Projection

**Status:** DONE

## Task ID

P7-003B

## Goal

Expose a deterministic, typed `citations` list beside the final Agent `report`,
derived only from the validated unified Evidence list.

## Why Now

P7-001/P7-002 already preserve Web URL and Project Document/Chunk provenance in
one Evidence collection, and P7-FE-001 has closed the scoped streaming path.
The smallest useful next step is to project that provenance into a stable Agent
output shape before any Citation UI, inline marker, or persistence design.

## Scope

- Add strict Citation models for `temporary_research` and `user_upload`.
- Add one pure Evidence-to-Citation mapper implementing D-017.
- Add `citations` to `AgentState` and `AgentOutputState`, not Agent input or Run
  context.
- Have Writer return `report`, final AI message, and `citations` in one State
  update. Writer LLM input remains only `research_query + evidence`.
- Preserve Evidence order and duplicates; assign `c1`, `c2`, ... after all Tool
  results have been aggregated.
- Cover Web, Project Document, mixed, duplicate, truncated-excerpt, no-Tool,
  invalid payload, and repeat-run final-output behavior.
- Update Agent output and architecture documentation after implementation.

## Out of Scope

- Inline report markers, claim-to-Citation links, structured Writer output,
  citation correctness/faithfulness evaluation, or changing Writer prompts.
- Citation/Sources UI, custom progress events, replay history, `run_id`,
  `report_id`, PostgreSQL storage, or Product Backend Citation APIs.
- Evidence deduplication, retrieval-score filtering, fusion/reranking, Saved Web
  Source, or changes to Tool execution.
- Migration or fallback parsing for existing local LangGraph checkpoints.

## Acceptance Criteria

- Citation accepts exactly the two implemented source types and preserves their
  approved provenance fields without including `retrieval_score` or
  `relevance_note`.
- The mapper revalidates its input, preserves order and duplicates, assigns
  contiguous IDs starting at `c1`, and never reads ToolMessage/report text.
- `excerpt` strips only leading/trailing whitespace and is at most 500 Unicode
  code points, using the first 499 plus `…` when truncated.
- Web URL/capture time and Project `document_id`/`chunk_id`/filename plus
  optional page/section fields survive mapping and JSON serialization.
- Writer returns `report` and its Citation list in the same node update. A
  no-Tool Report returns `citations: []`; a mapping/Writer failure returns no
  partial new final-output update.
- A fresh-thread Graph test proves final output contains messages, report, and
  citations. Existing development checkpoints are neither migrated nor
  deleted.
- Existing Python tests, warnings-as-errors run, dependency check, compilation,
  and `git diff --check` pass without unrelated changes.
