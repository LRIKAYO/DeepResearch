Key Decisions:

  remains a direct Frontend-to-Agent connection.
- The environment value is an exact allow-list, not a wildcard and not an Auth
  mechanism.
- The small `create_app()` entry point lets tests exercise startup configuration
  without mutating the production application instance.

What the user should understand:

- CORS tells a browser which origins may call the Product Backend; it does not
  authenticate a user or enable credentials.
- Local allowed origins are configured with `RESEARCHFLOW_CORS_ORIGINS` before
  starting Uvicorn; an unset value leaves the Backend without CORS middleware.
- P5-002 will still obtain a Product session from this Backend, then stream
  directly to Agent Server using that session's derived `thread_id`.

Architecture Impact: None. This implements the already approved D-011 transport
boundary without changing Product, Research Session, or Agent Contracts.
